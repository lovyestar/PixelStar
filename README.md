# PixelStar
###### Made By Yestar_ 💫 
### Custom UI for Pixelmon Modpack (only 9.4.0)
---

* #### Features
    * 커스텀 UI 지원
    * 픽셀몬 로그 자동 넘기기
    * 효과적인 스킬 시각적 표시 지원
---
Pixelmon에는 배틀 스킬을 사용하기 위한 UI가 존재합니다.  
다른 UI를 사용하지 않고 기존 UI로 배틀을 진행할 시 다음과 같은 화면으로 진행하게 됩니다.
<img width="1800" height="1131" alt="Image" src="https://github.com/user-attachments/assets/d9bec8aa-0e5a-4128-a190-c8b502ff49f5" />
위와 같은 화면은 하단 화면을 가리고, 필요한 정보가 일부 부족하며, 개방감이 부족하다는 단점이 존재합니다.

그래서 화면을 가리지 않고, 필요한 내용을 모두 전달해주는 간편한 UI가 필요해졌습니다.

*PixelStar*는 위와 같은 문제를 해결하고 배틀 화면을 보다 쾌적하게 제공하며, 일관성 있고 필요한 정보만 담긴 UI를 제공합니다.
